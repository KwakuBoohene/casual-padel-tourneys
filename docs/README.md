# Documentation

This folder contains maintained references for current API contracts, architecture, domain rules, setup and operation of the application.

Feature proposals, implementation plans, ticket breakdowns, local verification results, benchmark reports and source-data notes belong in the local `plans/` folder, which is Git-ignored. Keep links in versioned documentation pointed at other maintained, versioned references.

Update the relevant reference when application behavior changes. Do not use this folder as an implementation diary or duplicate migration inventories already maintained in the codebase.
